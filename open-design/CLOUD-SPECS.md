## Операторская консоль (роль operator)

### 1. Abuse Console (L)
Лента флагов антиабьюза. Карточка флага: 🚩 тип
(`multi_account_device` | `ip_farm` | `token_spike` | `disposable_email`),
якоря: user → key → IP → device_id, время. Действия кнопками:
`Restrict key` / `Suspend team` / `Allowlist`. Свайп вправо = allowlist,
влево = restrict (как почта). Источник: `/api/admin/abuse-flags`.
Состояния: Loading — штриховка; Empty — «🟢 abuse clean».

### 2. Free Tier Matrix (L)
Таблица `Model × лимит токенов/день` — inline-редактирование карандашным
инпутом, toggle вкл/выкл модели во фри-тире. Верхняя строка: глобальный
дневной бюджет фри-COGS прогресс-бар + поле «перелив $/мес» (дефолт 10).
Дефолт новой модели: 50M токенов/день. Источник:
`/api/control/v1/tier-policies` → снапшот.

### 3. Sources Health (M)
Источники владельца и бесплатные полосы: 🟢/🟡/🔴 живость (уже считается
cooldown/circuit), weight slider 0–100 (приоритет роутера), счётчик
«токенов сегодня» по источнику. Long press → jiggle: удалить/переименовать.

### 4. Identity Graph (XL)
Граф `user → keys → IPs → devices`: узел-человек, ключи квадраты, IP круги,
device треугольники; связи-флаги красным карандашом (>2 аккаунтов на
device, >5 ключей на IP/день). Клик по узлу — карточка действий.
Источник: `/api/admin/identity-graph?user=`.

### 3b. Sources Matrix (L) — multi-provider alias
Страница модели: строки = источники (провайдеры/аккаунты), колонки:
override имени апстрим-модели (инпут), weight slider, drag-порядок =
failover-очередь, input/output $/Mtok (пусто ⇒ наследует цену алиаса),
🟢/🟡/🔴 circuit, toggle. Кнопка «+ источник». Данные:
`sources[]` снапшота; telemetry пишет фактический upstream_model.
Семантика: cheapest/fastest/sticky считаются пер-источниково; стик-сессия
пиннит к источнику (кэш сохраняется).

## Юзерский дашборд (тенант)


### 5. Balance (S)
Кредиты крупно, бейдж «never expire». Дельта за неделю мелко.

### 6. Usage Today (M)
Токены сегодня / лимит фри-тира (напр. 12.4M / 50M) кольцевым прогрессом;
mini-bars разбивка по моделям. При ≥90% — жёлтый карандаш и подсказка
«лимит сбросится в 00:00 UTC».

### 7. Keys (L)
Список ключей: prefix, models, RPM, создан. Создание ключа — модалка;
первый ключ требует Turnstile-токен. Лимит ключей на юзера: 5 (флаг
антиабьюза при попытке большего).

### 8. Top-up (M)
Паки $5/$20/$50 (+бонус-бейджи) → Paddle overlay; блок USDT: адрес, сумма,
код-мемо, инпут txid → статус pending. Подпись «любое пополнение снимает
лимиты навсегда».

# Лендинг /cloud — спека (подцикл F, стиль landing/brief.md)
Тот же карандаш-словарь (#FFFBF0, Caveat/Patrick Hand, dashed-карточки,
wobble). Тон: по-человечески, цифрами, без маркетингового тумана.

1. **Hero**: от руки «Все модели — один ключ. Без своих аккаунтов.»
   Подзаголовок «2papi Cloud: дешёвый доступ к LLM с честным роутингом».
   CTA-стикер «Забрать фри-план», второй «Сколько это стоит ↓».
2. **How it works**: 3 карточки-шага — Регистрация → Ключ → base_url в
   твой инструмент. Рядом пресет-таблички: Cline / Roo / Claude Code /
   Codex CLI / SillyTavern (готовые конфиги).
3. **Cost per task** (витрина): график от руки «одна и та же задача:
   обычный API $X · OpenRouter $Y · 2papi $Z» + строка мелко «замер:
   RTK+кэш-sticky, методология в блоге». Цифры — только из реальных
   прогонов (battle-test).
4. **Models**: программатическая лента моделей с ценами за Mtok
   (генерится из каталога, как SEO-страницы OR).
5. **Pricing**: три колонки-карточки:
   - **Free** ($0 навсегда): 50M токенов/день, модели фри-полосы; честная
     подпись «в часы пик возможна очередь»; без карты.
   - **PAYG** (пополнение от $5): все модели, наценка уже в цене,
     credits never expire, без минимальной комиссии пополнения.
   - **Code** ($10/мес, стикер «скоро»): fair-use кодинг-план, пул
     open-weight кодеров, Anthropic-format endpoint.
6. **Trust**: «Мы не бьём ваш кэш» (sticky routing), X-Gateway-Route
   (видишь, кто обслужил), статус провайдеров живьём, credits не сгорают.
7. **FAQ**: откуда модели (официальные API + наши источники; никаких
   серых пулов подписок), возвраты/сгорание, оплата (карты мира через
   Paddle, крипта), кто вы (ФОП Украина, контакты).
8. **Footer**: ссылка на OSS 2papi («умеешь свои ключи? — self-host»),
   статус-борд, Telegram-канал.

## Антиабьюз-якоря (серверная часть к экранам)
- Иерархия метринга: virtual_key (50M ткн/день) → user (сумма ключей) →
  IP (мягкий кап ~150M ткн/день + ≤5 новых ключей/день) → device_id.
- device_id: salted hash сигналов браузера (canvas/шрифты/tz/UA) при
  сигапе; таблица devices ↔ users; >2 аккаунтов/device → флаг.
- X-Forwarded-For доверять только при TRUSTED_PROXY (иначе спуфинг).
- Multi-user IP (офис/CGNAT): порог повышается консервативно, не бан
  (паттерн WorkOS Radar / Cloudflare multi-user detection).
- Fingerprint Pro ($99/мес) — апгрейд при первых инцидентах.

## Identity Clusters (антиабьюз v3, подцикл D)

Проблема: ферма N аккаунтов × 50M ткн/день. Решение: лимит фри-тира
привязан к КЛАСТЕРУ идентичности, не к аккаунту ⇒ ферма даёт ×0 выгоды.

### Серверная часть
- `identity_nodes`: (type, value_hash) ↔ user_id, timestamp. Типы узлов:
  email_normalized (+tag/dots срезаны), device_hash, ip_/24 на сигапе,
  password_hash, payment_hash (карта/кошелёк — при первом топапе),
  phone.
- Union-find job: ночной + событийный (signup/topup) → cluster_id на
  team. Новый аккаунт наследует бюджет и ТИР кластера.
- policy.go: токен-бакет фри-тира ключуется cluster_id.
- Ступени enforcement (по Stripe): low risk → ничего; medium (>2 акк/
  device или velocity) → phone step-up с carrier lookup; high → гейт
  фри-лимита до проверки (сигап НЕ блокируем).
- Поведенческий сигнал: сигап→ключ→макс-дрейн→dormant у аккаунтов одного
  дня = флаг кампании.

### Админка (дополнение Abuse Console)
- Вкладка **Clusters**: список кластеров (размер, сигналы-связки, суммарный
  дрейн), действия Merge / Split / Ban cluster / Trust. Раскрутка графа
  от подтверждённого абьюзера одной кнопкой.

### Экономика защиты
Всё строится из уже собираемых данных; вендоры (Fingerprint Pro $99,
SEON) — апгрейд при масштабе инцидентов, не на старте.
