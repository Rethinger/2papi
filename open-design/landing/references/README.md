# Референсы карандаш-стиля

Добавь сюда 3-5 ссылок/скринов, которые дизайнер должен посмотреть:

1. **Excalidraw hand-drawn** — https://excalidraw.com — эталон неровных линий, wobble.
2. **Sketchbook paper texture** — https://www.figma.com/community/file/125303476 — бумага #FFFBF0 + точки.
3. **Pencil filter feTurbulence** — https://developer.mozilla.org/en-US/docs/Web/SVG/Element/feTurbulence — для живости обводки.
4. **iOS widgets drag** — https://support.apple.com/guide/iphone/add-widgets-iph9a2a69136 — грид и перетаскивание.
5. **Caveat font** — https://fonts.google.com/specimen/Caveat — заголовки.

Сюда же кидай скрины понравившихся лендингов с карандашом.
